# Portfolio — Archive Template

An 18-slide, 1920×1080 portfolio template for a social media & brand designer.
Folder/archive aesthetic: paper textures, index tabs, polaroids, clips and an OS-style chrome.
Every text field is a `[placeholder]` and every hatched box is a drop zone for your work.

- `Portfolio-Archive-Template.pdf` — the finished deck (import into Canva: Create → Import file)
- `preview/` — a JPG of every slide
- `src/deck.html` + `src/deck.css` — the slide source
- `src/scene.html` + `src/render-assets.js` — generates the grass, sky, paper and felt textures in `assets/`
- `src/render-deck.js` — renders previews (`node render-deck.js`) and the PDF (`--pdf`)
