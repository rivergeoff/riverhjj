# yuga matcha — Instagram feed mockup

A profile-page mockup for **yuga matcha** (matcha café) in a blue + green palette.
Open `index.html` in a browser; `preview.png` is a 2x render.

## Using your own photos

Every tile is an illustration by default. Save a photo as `assets/post-1.jpg` …
`assets/post-9.jpg` (left to right, top to bottom, 4:5 crop) and it replaces that tile.

Palette: matcha `#5f9150`, deep green `#2f6343`, mint `#cfe5c4`, sky `#8fb9e0`,
blue `#2c5f9e`, navy `#1d3b63`, cream `#f5f2e7`.
